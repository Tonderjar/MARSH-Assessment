# Marsh — FP&A Regional Analysis

Automated financial analysis tool for regional transaction data. Reads raw transaction files across multiple formats, converts all amounts to USD using budget FX rates, and produces fully formatted Excel reports and an executive PowerPoint deck.

---

## Deliverables

| # | Deliverable | Location |
|---|---|---|
| D1 | Full FP&A Analysis Report (Excel) | `output/Deliverable_1_FPA_Analysis.xlsx` |
| D2 | Latin America Report (Excel) | `output/Deliverable_2_LatinAmerica.xlsx` |
| D3 | Executive Deck (PowerPoint) | `docs/Deliverable_3_ExecutiveDeck.pptx` |
| D4 | Desktop GUI Application (Windows exe) | `dist/MARSH_FPA_Report_Generator.exe` |

D1 and D2 are generated by the app or programmatically. D3 is a pre-built standalone deck. D4 is the self-contained executable built from `build.bat`.

## Requirements

Python 3.11+

```
pip install -r requirements.txt
```

Dependencies: `pandas`, `openpyxl`, `matplotlib`, `jinja2`, `pywin32`

> **Note:** `pywin32` is required for two features — injecting a real Excel PivotTable into D1, and sending reports via Outlook. Both features degrade gracefully (with a warning) if `pywin32` is not installed.

## How to Run

### Option 1 — Desktop App (recommended) — Deliverable 4

```bash
python src/main.py
```

Or launch the pre-built executable (no Python required):

```
dist/MARSH_FPA_Report_Generator.exe
```

**App features:**

- **Data Folder** — select the root folder containing all `DataTrans_*` files
- **FX Rates File** — auto-detected inside the data folder if left blank
- **Save Report As** — auto-suggested as `output/Deliverable_1_FPA_Analysis.xlsx` using a walk-up search for the project's `output/` folder
- **Report Type** — checkboxes to generate D1 (Full Analysis), D2 (LATAM), or both
- **Month Filter** — restrict the analysis to a specific month range; year is inferred from the data folder name
- **Generate Report** — runs the pipeline on a background thread with live progress output
- **Open Report** — opens the generated file in Excel when done
- **Send via Outlook** — opens a file picker directed at the `output/` folder; select files to attach, enter a recipient, and an Outlook draft is opened for review before sending
- **Session logging** — every run writes a timestamped log to `logs/` at project root

### Option 2 — Jupyter Notebooks

| Notebook | Covers |
|---|---|
| `full_analysis_report.ipynb` | Full regional analysis (D1 scope) |
| `latin_america_report.ipynb` | LATAM-only analysis (D2 scope) |

### Option 3 — Programmatic (Python API)

```python
from src.engine import generate_report, generate_latam_report

# Deliverable 1 — Full analysis
d1 = generate_report(
    data_root="data/2024",
    output_path="output/Deliverable_1_FPA_Analysis.xlsx",
)

# Deliverable 2 — LATAM report
d2 = generate_latam_report(
    data_root="data/2024",
    output_path="output/Deliverable_2_LatinAmerica.xlsx",
)
```

Both functions accept optional `date_from` / `date_to` datetime parameters for filtering and a `progress_cb` callable for streaming progress messages.

## Data Format

The engine handles inconsistent real-world files automatically:

| Scenario | Handled |
|---|---|
| CSV with comma or semicolon delimiter | ✓ separator auto-detected |
| Header row not on row 0 | ✓ scanned dynamically |
| Extra columns (e.g. `id`) | ✓ ignored — only required columns selected |
| Mixed CSV and XLSX in the same folder | ✓ |
| Currencies not in FX file | excluded from USD totals |
| USD not listed in FX file | defaulted to rate 1.0 |

Transaction files must be named `DataTrans_N.csv` or `DataTrans_N.xlsx` and contain at minimum the columns `Client`, `Country`, `Currency`, `Transaction` (any order, any row).

See `ProblemSolved.md` for a detailed write-up of the data ingestion challenge and how it was resolved.

## D1 Report Contents

| Sheet | Contents |
|---|---|
| Executive Summary | KPI tiles (total revenue, transactions, clients, countries) and sheet index |
| Txns by Client & Currency | Count, local total, and USD total per client-currency pair |

| Geographic Analysis | Country revenue ranking with bar chart |

| Sheet | Contents |
|---|---|
| Executive Summary | LATAM-scoped KPI tiles |
| LATAM Transactions | Full row-level transaction detail for Latin America |
| Client Revenue (USD) | LATAM clients ranked by revenue with bar chart |
| Geographic Analysis | Revenue by LATAM country |
| Restricted Clients (Q4) | Clients with transactions in restricted jurisdictions (Russia, Cuba, China, Venezuela) during Q4 — highlighted in red |
